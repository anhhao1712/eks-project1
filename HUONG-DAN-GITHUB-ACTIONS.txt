6. Ý NGHĨA CÁC STAGE
- infra: tạo/cập nhật hạ tầng AWS.
- platform: cài/cập nhật EBS, Argo CD, Kubernetes Secrets và root-app.
- all: chạy infra rồi platform trong một lần; KHÔNG build image.
- refresh: cập nhật credentials SQS và restart các deployment dùng SQS.
Nếu dùng all từ đầu, sau khi xanh vẫn cần chạy app-cd pipeline để publish image.
Các workflow infra/app-cd/destroy dùng cùng nhóm concurrency để tránh chạy đồng thời.

10. GIỚI HẠN LEARNER LAB VÀ CÁCH ĐÃ XỬ LÝ
- iam:CreateRole đã bị từ chối: Terraform dùng LabRole cho EKS/node; không dùng OIDC/IRSA mới.
- LabRole có trust EKS/EC2 và PassRole đã được bạn xác nhận; giữ cấu hình hiện có.
- EBS controller dùng mạng host để lấy quyền node LabRole; không cần sửa trust policy.
- Secrets/SQS dùng Kubernetes Secrets do Terraform quản lý; credentials SQS có thời hạn.
- Cluster hiện tại do voclabs tạo; runner dùng credentials cùng role để giữ quyền Kubernetes.
- GitHub runner truy cập EKS API public; endpoint hiện tại hỗ trợ việc này.
- Hạn mức/ngân sách của Lab vẫn áp dụng; GitHub không tăng quyền hoặc quota AWS.
- Phiên/token hết hạn giữa workflow có thể làm apply dở dang; cập nhật secrets và chạy lại cùng stage/bucket.
- Nếu lỗi quyền AWS, dừng xem action bị từ chối; không đổi state hoặc cố tạo role khác.
